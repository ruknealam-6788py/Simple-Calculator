# Simple Calculator

## Overview

This repository contains a menu-driven calculator program developed in Python. The project is designed to practice fundamental programming concepts by allowing users to perform different arithmetic operations through a simple text-based menu.

The calculator supports multiple user inputs for each operation and continues running until the user chooses to exit the program. It also handles invalid menu selections and prevents division or modulus by zero.

## Features

- Menu-driven interface
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Multiple number input
- Continuous execution until exit
- Invalid menu option handling
- Division by zero protection
- Modulus by zero protection

## Concepts Used

- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)
- Loops (while and for)
- Input Validation
- Error Handling

## Project File

- simple_calculator.py

## Learning Objectives

This project demonstrates how to:

- Build a menu-driven Python application.
- Use conditional statements to control program flow.
- Process multiple user inputs using loops.
- Perform arithmetic operations.
- Validate user input and handle common errors.
- Write clean, readable, and well-organized Python code.

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code or any Python IDE.
3. Run the simple_calculator.py file.
4. Follow the on-screen menu to perform calculations.
